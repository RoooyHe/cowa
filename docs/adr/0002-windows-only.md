# 只支持 Windows

cowa 只在 Windows 上运行。这是拿**采集保真度**换**可移植性**：要求的字段清单里，主板型号、内存条厂商与单条拆分、显卡子厂商与显存、显示器 EDID 型号与物理英寸、声卡列表，全落在跨平台采集库（`sysinfo` 一类）的舒适区之外，只有 Windows 的 WMI/CIM 与注册表能给出。走跨平台，这份清单会缩水到只剩 CPU / 内存总量 / 磁盘 / 网卡 / OS / 分辨率——那就不是这张屏幕了。

反面同样重要：macOS 与 Linux 永远不会跑 cowa，尽管 Tauri 本身是跨平台的。因此 UI 里可以坦然使用 Windows 专有的概念（盘符、WMI 字段、EDID 显示器），**不为假想的第二个平台留抽象层**——不为一个不存在的需求付税。
