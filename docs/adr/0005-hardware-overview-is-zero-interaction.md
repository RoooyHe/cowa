# 硬件概览是零交互的

> **状态：已被 `ADR-0007` 取代。** 零交互的作用域从「整个应用」收窄为「`硬件概览` 的内容」——第 2 屏及其 `标签栏` 现已存在。下面的论证除作用域与「导航壳」一项外仍然成立。

`硬件概览` 上**没有任何可点元素**。没有刷新、没有导航、没有设置、没有右键菜单、没有主题开关。这块屏幕只做一件事：把快照项画出来。

这一条在一次会话里被撞了四次，每次都挡回去了：

1. **刷新按钮** —— `ADR-0001`：值永远不会变，刷新按钮是骗人的。
2. **导航壳** —— 第 2 屏还不存在，不为一个不存在的需求付税（同 `ADR-0002` 的逻辑）。
3. **设置页** —— 没有可设置的东西。
4. **主题开关** —— 主题纯跟随系统（`prefers-color-scheme`），想换就去改 Windows 的设置。**屏上不出现深色模式按钮，也不出现键盘快捷键。**

**为什么这么硬。** 因为这是一个「零」而不是「一」。只要开了第一个口子，「再加一个复制按钮」就顺理成章——而每一个控件都要回答「点了之后发生什么」，也就都要把 cowa 从**信使**（`ADR-0003`）拉回**有状态的应用**。而这块屏幕的价值恰恰在于它**没有状态**：没有「当前选中项」、没有「已加载更多」、没有「用户偏好」。它是一张写满事实的纸，不是一个应用。

**后果。** 想固定主题的用户做不到，只能改系统设置；想把配置贴出去的用户复制不了，只能截图。这是明知故犯的取舍：宁可少几个功能，也不要有第一个按钮。
